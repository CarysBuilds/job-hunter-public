# Job Hunter Friend 使用说明

Job Hunter Friend 是在 Windows 本机运行的求职助手。它支持从 BOSS 直聘、猎聘和智联招聘抓取岗位，并按求职偏好和简历中的能力词进行本地评分，无需配置模型 API。

## 安装与打开

1. 安装 Google Chrome。
2. 双击 `JobHunter-Friend-Setup-x64.exe`，按提示安装。支持 Windows 10/11 x64。
3. 从桌面或开始菜单打开 **Job Hunter Friend**。
4. 如果浏览器没有自动打开，请访问 [本机操作界面](http://127.0.0.1:17322)。访问时需保持程序运行。

本版本未进行商业代码签名，Windows 可能显示开发者无法验证的提示。请确认安装包来源后再运行。

## 第一次抓取

1. 进入“设置”，填写抓取关键词、城市和个人求职偏好。
2. 关键词可以用英文逗号、中文逗号、顿号或分号分隔。界面会显示拆分后的关键词，便于核对。
3. 例如 `产品经理，产品运营,用户运营` 会分别执行三次搜索，每次只搜索一个关键词；英文岗位名称中的空格会保留。
4. 点击对应平台的“打开登录”，在独立 Chrome 窗口完成登录。
5. 点击对应的抓取按钮，等待任务结束。多个关键词和城市会逐项搜索，结果在岗位列表中合并并去重。

开始抓取前只需登录本次要使用的平台。抓取期间保持该 Chrome 窗口打开；遇到验证时请在平台页面人工处理，避免连续重复抓取。

## 岗位评分

在“设置”填写目标方向、经验、薪资和城市偏好。简历可选：填写至少 80 个字符的简历正文后，程序会在本机匹配简历与岗位描述中的能力词。保存修改后，点击“重新评分”更新已有岗位。

未填写简历时，能力维度不加分。评分用于辅助筛选；请结合职位描述判断岗位是否适合。

## 自填模板与批量打招呼

批量发送支持 BOSS 直聘。猎聘和智联的岗位可在详情中复制模板，由你在平台手动发送。

1. 打开“批量打招呼”，填写并保存自己的打招呼模板，最多 500 个字符。
2. 点击“刷新候选”。候选只包含当前有效、尚未沟通的 BOSS A/B 岗位，并排除猎头岗位及命中屏蔽规则的岗位。
3. 点击“选择 A 档”“选择 B 档”或“选择 A+B 档”，也可以逐项勾选。每批最多 20 个；候选较多时，快捷选择只选排序靠前的 20 个。
4. 点击“预览选中的岗位与文案”，核对名单及完整内容。
5. 点击“确认并发送”。程序逐条发送，每条之间等待约 10–20 秒。请保持 BOSS 窗口打开，期间不要切换该窗口中的岗位或聊天对象。
6. 在页面查看每条结果；需要停止时点击“停止后续发送”。当前岗位核对完成后，不再发送下一条。

模板会原样发送给所有选中岗位，不会自动改写、补充经历或替换占位符。不需要 API Key，也不需要上传简历。请在确认前检查内容适合所有选中的岗位。

程序会核对平台上的本人消息气泡，确认后登记“已打招呼”。遇到登录验证、页面异常或无法确认发送结果时，本批任务停止。已经尝试发送的岗位不会自动重发，即使重启程序或重置沟通状态也不会重新加入候选。

“发送待确认”不代表一定失败。请到 BOSS 查看实际聊天记录；若已发送，可在岗位详情中人工登记已沟通。未开始发送的剩余岗位可在刷新候选后重新选择。

## 数据与隐私

- 数据目录：`%APPDATA%\JobHunterFriend\data`。按 `Win + R`，粘贴路径并回车即可打开。
- 该目录保存岗位、设置、简历、模板、发送记录和独立 Chrome 登录状态。
- 模板只保存在本机；确认发送时会发送到 BOSS。评分不调用外部模型服务。
- “更多”页面可导出岗位和沟通记录，分享前请检查其中的个人信息。
- 本版本使用独立安装目录、数据目录和端口，可与公开通用版并存；不会自动导入通用版或其他电脑的数据。
- 卸载程序会保留用户数据。彻底清除数据前，请先退出程序及其 Chrome 窗口。
